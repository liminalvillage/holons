# HolonsBot - 50 Features

A decentralized community coordination platform built as a Telegram bot.

---

## Quest System
1. **Create Tasks** - Work items that need doing (`/task`)
2. **Create Events** - Scheduled gatherings or activities (`/event`)
3. **Create Offers** - Resources or skills being offered (`/offer`)
4. **Create Requests** - Needs the community can help with (`/request`)
5. **Join/Leave Quests** - Participate in community quests
6. **Time Logging** - Track hours contributed to quests
7. **Quest Completion** - Mark quests done with appreciation prompts
8. **Recurring Tasks** - Create repeating quests (daily, weekly, custom)
9. **Quest Reminders** - Automatic notifications before deadlines

## Visual Display
11. **Image Mode** - Rich visual quest cards with status indicators
12. **Fast Mode** - Simplified images for quick generation
13. **Text Mode** - Lightweight text-only display option
14. **Smart Caching** - Background image regeneration for performance

## Hologram System
15. **Live-Updating Messages** - Telegram messages that auto-update when source changes
16. **Cross-Holon Sync** - Quests shared across federated communities
17. **Personal Holograms** - User-specific views in personal data space
18. **Hologram Deduplication** - Smart logic prevents duplicate references

## Expense Tracking
19. **Record Expenses** - Log shared expenses with description (`/expense`)
20. **Multi-Currency Support** - Track expenses in EUR, USD, and more
21. **Automatic Splitting** - Equal division among participants
22. **Balance Calculation** - Per-member balance tracking
23. **Expense Ledger** - View complete expense history (`/ledger`)
24. **Settlement Suggestions** - Optimal payment recommendations

## Federation
25. **Connect Holons** - Link communities together (`/spoon`)
26. **Disconnect Holons** - Separate federated communities (`/fork`)
27. **Lens Configuration** - Choose which content types to share
28. **Cross-Community Participation** - Join quests from federated holons

## Scheduling
29. **Calendar Picker** - Visual date selection for scheduling
30. **Time Picker** - Set specific times for events
31. **Cron Scheduling** - Flexible recurring schedule patterns
32. **Reminder System** - Configurable notification timing

## Leaderboard & Appreciation
33. **Community Leaderboard** - View member scores (`/leaderboard`)
34. **Value Equation** - Configurable scoring formula
35. **Send Appreciation** - Thank community members
36. **Activity Tracking** - Track all contribution types

## Lists & Checklists
37. **Standard Checklists** - General-purpose task lists (`/checklist`)
38. **Shopping Lists** - Toggle-based shopping lists (`/shopping`)
39. **Agenda Lists** - Schedule-based checklists (`/agenda`)
40. **Quest Subtasks** - Add checklists to any quest

## Role Management
41. **Create Roles** - Define community roles (`/addrole`)
42. **Assign Members** - Add users to roles
43. **Role-Based Checklists** - Responsibilities per role

## User Features
44. **Join/Leave Holon** - Membership management (`/join`, `/leave`)
45. **Personal Preferences** - Language and notification settings
46. **User Profiles** - Track participation history

## Internationalization
47. **Multi-Language Support** - 6 languages (en, it, es, fr, ru, de)
48. **Per-User Language** - Individual language preferences

## Data & Security
49. **Decentralized Storage** - HoloSphere/Nostr backend, community-owned data
50. **REA Accounting** - Event-sourced economic tracking with immutable history

*Built with Telegraf.js, HoloSphere.js, and decentralized principles.*
