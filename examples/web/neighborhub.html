How HoloSphere Powers NeighborHub

  • Neighborhood Holons: Each neighborhood or building is a geographic holon
  • Space Discovery: Find community spaces by location using H3 indexing
  • Federation: Spaces federate with event and activity holons
  • Real-time Availability: Subscribe to booking updates
  • Community-owned: No platform fee, no central authority

Code Example

// Initialize NeighborHub const hub = new HoloSphere('NeighborHub'); // List a community space await hub.put('downtown-hub', 'spaces', { id: 'community-hall-1', name: 'Community Hall', capacity: 50, hourly_rate: 0, amenities: ['WiFi', 'Projector', 'Kitchen'], available: true }); // Get all spaces in a neighborhood const spaces = await hub.getAll('downtown-hub', 'spaces'); // Book a space await hub.put('downtown-hub', 'bookings', { space_id: 'community-hall-1', event: 'Permaculture Workshop', date: '2025-11-15T14:00', organizer: 'LearnLocal' }); // Federate with LearnLocal for cross-platform booking await hub.federate('downtown-hub', 'learnlocal-events');
