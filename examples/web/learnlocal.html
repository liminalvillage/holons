How HoloSphere Powers LearnLocal

  • Location-Based Learning: Workshops tied to neighborhood holons
  • Skill Lenses: Organize by topic, skill level, or learning path
  • Federation: Learning resources shared across communities
  • Real-time Enrollment: Subscribe to new workshops and updates
  • Decentralized: No platform fees—communities own their education

Code Example

// Initialize LearnLocal with HoloSphere const learn = new HoloSphere('LearnLocal', strict=false); // Create a workshop await learn.put('downtown-learning-center', 'workshops', { id: Date.now().toString(), title: 'Introduction to Permaculture', topic: 'permaculture', skill_level: 'beginner', instructor: 'Jane Smith', description: 'Learn the basics of permaculture design...', max_students: 20, enrolled: 0, duration: 2, date: new Date('2025-12-01T14:00').getTime(), cost: 0, status: 'open', created: Date.now() }); // Get all workshops in a neighborhood const workshops = await learn.getAll('downtown-learning-center', 'workshops'); // Enroll in a workshop await learn.put('downtown-learning-center', 'enrollments', { workshop_id: 'workshop-123', student_name: 'John Doe', enrolled_at: Date.now() }); // Subscribe to new workshops learn.subscribe('downtown-learning-center', 'workshops', (workshop) => { console.log('New workshop:', workshop.title); }); // Federate with regional education networks await learn.federate('downtown-learning-center', 'regional-education'); // Workshops become discoverable across the network
