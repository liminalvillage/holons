CoopCreds

Cooperative credit and mutual aid network. Create lending circles, extend peer-to-peer credit, and organize mutual aid pledges to support community members without traditional banking infrastructure.

How HoloSphere Powers CoopCreds

  • Lending Circles: Self-organized groups pool resources and extend credit
  • Peer-to-Peer Credit: Direct lending without banks or credit agencies
  • Mutual Aid Networks: Pledge and track community support commitments
  • Trust-based Scoring: Reputation built on community relationships, not credit scores
  • Transparent Terms: All agreements stored on member-controlled holons
  • Integration with LocalLoop: Credit denominated in local currency

Code Example

// Initialize CoopCreds mutual aid system const coopcreds = new HoloSphere('CoopCreds'); // Create a lending circle await coopcreds.put('portland-mutual-aid', 'lending-circles', { id: Date.now().toString(), name: 'Downtown Small Business Circle', members: 8, pool_size: 5000, term_months: 12, created: Date.now() }); // Request credit from the community await coopcreds.put('portland-mutual-aid', 'credit-requests', { id: Date.now().toString(), borrower: 'alice@local', amount: 500, purpose: 'Business startup', repayment_plan: '50 LC per month for 10 months', status: 'pending', timestamp: Date.now() }); // Pledge mutual aid to community await coopcreds.put('portland-mutual-aid', 'mutual-aid', { id: Date.now().toString(), pledger: 'bob@local', type: 'Housing', details: 'Emergency housing for up to 2 weeks', available: true, timestamp: Date.now() }); // Get all active lending circles const circles = await coopcreds.getAll('portland-mutual-aid', 'lending-circles'); // Track repayments await coopcreds.put('portland-mutual-aid', 'repayments', { id: Date.now().toString(), credit_request_id: 'req-123', amount: 50, timestamp: Date.now() }); // Subscribe to new credit requests coopcreds.subscribe('portland-mutual-aid', 'credit-requests', (request) => { console.log(`New credit request: ${request.borrower} needs ${request.amount}`); }); // Federate with LocalLoop for currency integration await coopcreds.federate('portland-mutual-aid', 'portland-hours');
