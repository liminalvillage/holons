# HolonsBot Schema Scripts

This directory contains scripts for managing JSON schemas in the HolonsBot project.

## Scripts

### 📤 uploadSchemas.js
Uploads all JSON schemas from the `schemas/` directory to the holosphere for global access.

```bash
# Upload all schemas
node scripts/uploadSchemas.js

# Or make it executable and run directly
./scripts/uploadSchemas.js
```

**Features:**
- Uploads all `.json` files from the schemas directory
- Creates a schema registry for easy discovery
- Provides upload progress and error reporting
- Generates a verification script automatically

### 🛠️ schemaManager.js
Comprehensive schema management tool for interacting with schemas in the holosphere.

```bash
# List all available schemas
node scripts/schemaManager.js list

# Download a specific schema
node scripts/schemaManager.js get quest

# Validate data against a schema
node scripts/schemaManager.js validate user ./test-data.json

# Update/upload a schema
node scripts/schemaManager.js update ./schemas/quest.json

# Compare local vs remote schema
node scripts/schemaManager.js compare expense

# Show help
node scripts/schemaManager.js help
```

**Features:**
- List all schemas in the holosphere
- Download schemas locally
- Validate JSON data against schemas
- Update existing schemas
- Compare local and remote schema versions
- JSON Schema validation using AJV

### 🔍 verifySchemas.js
*(Auto-generated by uploadSchemas.js)*

Verifies that all uploaded schemas are accessible in the holosphere.

```bash
node scripts/verifySchemas.js
```

## Requirements

- Node.js (ES modules support)
- HoloSphere package
- AJV for JSON Schema validation (for schemaManager.js)

## Schema Directory Structure

```
schemas/
├── quest.json          # Quest/task schema
├── expense.json        # Expense tracking schema
├── user.json           # User profile schema
├── shopping.json       # Shopping list item schema
├── checklist.json      # Checklist schema
├── announcement.json   # Announcement schema
├── role.json           # Role schema
├── tag.json            # Tag schema
├── settings.json       # Settings schema
├── event.json          # Event schema
└── hologram.json       # Hologram schema
```

## Holosphere Storage

Schemas are stored in the holosphere with the following structure:

- **Global path**: `schemas/{schema-name}`
- **Registry path**: `schema_registry`

Each schema includes metadata:
```json
{
  "metadata": {
    "uploadedAt": "2023-XX-XXTXX:XX:XX.XXXZ",
    "version": "1.0.0",
    "source": "HolonsBot",
    "filename": "quest.json"
  }
}
```

## Usage Examples

### Upload all schemas to holosphere
```bash
cd /path/to/HolonsBot
node scripts/uploadSchemas.js
```

### Validate quest data
```bash
# First, get the schema
node scripts/schemaManager.js get quest

# Then validate your data
node scripts/schemaManager.js validate quest ./my-quest-data.json
```

### Update a schema
```bash
# Edit your schema file
vim schemas/quest.json

# Upload the updated version
node scripts/schemaManager.js update schemas/quest.json
```

## Error Handling

Both scripts include comprehensive error handling:
- Network connectivity issues
- Invalid JSON files
- Missing dependencies
- Schema validation errors

## Development

To add a new schema:

1. Create the schema file in `schemas/`
2. Follow JSON Schema draft-07 format
3. Include proper metadata
4. Run `uploadSchemas.js` to upload to holosphere
5. Use `schemaManager.js` to verify and manage

## Integration with HolonsBot
